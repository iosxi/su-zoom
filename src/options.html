ルール

ルールは ドメイン だけでも、ドメイン/パス でも、 ドメイン/パス?クエリ でも書けます。 URL から https:// と # 以降を取り除いたものが、 書いた文字列で始まるページすべてに効きます。

書きかたの例

example.com/cat/news/japan と書いた場合:

  • https://example.com/cat/news/japan
  • http://example.com/cat/news/japan/1001
  • http://example.com/cat/news/japanese
  • http://example.com/cat/news/japan?page=1
  • https://example.com/cat/news/usa
  • http://example.com/cat/news/china?cat=japan

japanese にも効くのは、単純な前方一致だからです。 区切りで止めたいときは末尾に / を付けて example.com/cat/news/japan/ と書いてください。

クエリで中身が変わるサイトのために、? 以降も書けます。

  • example.com?cat=japan → https://example.com/?cat=japan&page=2
  • example.com?cat=japan → https://example.com/?cat=usa

複数のルールが当たるときは、いちばん細かいものが勝ちます (ホストの完全一致 > ホストが長い > パスが長い)。

有効 ルール ズーム

まだルールがありません。

ルールに一致しないページ

  • すべてのページの既定の倍率を決めます。 Firefox がサイトごとに覚えている倍率は上書きされます。

  • ルールのないページには手を出しません。Ctrl + マウスホイールなどで 変えた倍率がそのまま残ります。

その他

ルールの持ち出しと取り込み

ルールを JSON として取り出したり、貼り付けて取り込んだりできます。 取り込むと、同じルールは上書きされ、無いものは追加されます。
