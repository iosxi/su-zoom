# su-zoom

ページごとのズームを固定する Firefox の拡張機能です。すべて日本語で使えます。

Firefox は本来「既定のズーム倍率」を設定できません。su-zoom はそれを可能にし、
さらに **ドメインだけでなく URL のパスの途中まで** 指定してズームを決められます。

---

## できること

**サイトの一部分だけを大きくできる**

ルールは `example.com` のようなドメインだけでなく、
`example.com/cat/news/japan` のようにパスの途中まで書けます。
URL から `https://` と `#` 以降を取り除いたものが、書いた文字列で
**始まる**ページすべてに効きます。

`example.com/cat/news/japan` と書いた場合:

| URL | 効く |
| --- | --- |
| `https://example.com/cat/news/japan` | ○ |
| `http://example.com/cat/news/japan/1001` | ○ |
| `http://example.com/cat/news/japanese` | ○ |
| `http://example.com/cat/news/japan?page=1` | ○ |
| `https://example.com/cat/news/usa` | × |
| `http://example.com/cat/news/china?cat=japan` | × |

上の表のいちばん下が効かないのは、`example.com/cat/news/china?cat=japan` が
`example.com/cat/news/japan` で始まっていないためです。

**クエリ (`?` より後ろ) もルールに書けます。** どのページかがクエリで決まる
サイトのためです。`example.com?cat=japan` と書いた場合:

| URL | 効く |
| --- | --- |
| `https://example.com/?cat=japan` | ○ |
| `https://example.com/?cat=japan&page=2` | ○ |
| `https://example.com/?cat=usa` | × |
| `https://example.com/` | × |

見ないのは `#` より後ろだけです (同じページの中の位置を指すものなので)。

**すべてのページの既定の倍率も決められる**

ルールに当たらないページをまとめて 110% にする、といった使いかたができます。
これは Fixed Zoom と同じ機能です。触ってほしくない場合は
「Firefox の設定にまかせる」を選べます。

**ツールバーから 2 手で決められる**

ツールバーの単眼鏡ボタンを押すと、今のページのズームをその場で上げ下げできます。
気に入った倍率で「このズームで保存」を押せばルールになります。
どこまでを対象にするかは、`example.com` から
`example.com/cat/news/japan/1001` まで候補が並ぶので選ぶだけです。

**今の倍率がいつでも分かる**

ツールバーのアイコンに現在の倍率が出ます (既定では 100% 以外のときだけ)。

**日本語のみ**

画面も説明もすべて日本語です。

## 入れかた

### 署名済みの XPI を受け取った場合

XPI ファイルを Firefox のウィンドウにドラッグ＆ドロップし、表示される確認で
「追加」を選びます。ツールバーに単眼鏡のアイコンが増えます。

### 未署名の XPI を受け取った場合

通常版の Firefox には恒久インストールできません (署名が必須のため)。
一時的に読み込んで試せます。

1. アドレスバーに `about:debugging#/runtime/this-firefox` と入力
2. 「一時的なアドオンを読み込む」を押し、XPI ファイルを選ぶ

この方法で入れたものは **Firefox を終了すると消えます**。試用向けです。

## 使いかた

### ページを見ながらルールを作る

1. 大きくしたいページを開く
2. ツールバーの単眼鏡ボタンを押す
3. `＋` `−` で好みの大きさにする (その場で効きます。まだ保存されていません)
4. 「どこまでを対象にするか」で範囲を選ぶ
5. 「このズームで保存」を押す

ルール欄は手で書き換えられます。`https://` を付けたまま貼り付けても、
保存するときに落ちます。

### ルールをまとめて見る・直す

ツールバーのポップアップ右上の「設定」、または `about:addons` の su-zoom の
「設定」から開きます。ここでは次のことができます。

- ルールの追加・書き換え・削除、一時的な入り切り
- ルールに当たらないページの既定のズーム
- サブドメインにも適用するかどうか
- ツールバーに倍率を出すかどうか
- ルールの書き出しと取り込み (JSON)

### 複数のルールが当たるとき

いちばん細かいものが勝ちます。強い順に **ホストの完全一致 > ホストが長い >
パスが長い** です。

| ルール | `news.example.com/sports/baseball` に効くのは |
| --- | --- |
| `example.com` | |
| `example.com/sports` | |
| `news.example.com` | ← これ (ホストが完全に一致するため) |

`example.com/sports/baseball` のように、より長いパスのルールを
`news.example.com` に対して作れば、そちらが勝ちます。

### 区切りで止めたいとき

前方一致なので、`example.com/cat` は `example.com/category` にも効きます。
止めたいときは末尾に `/` を付けて `example.com/cat/` と書いてください。

### クエリを書くときの注意

前方一致なので、書いた順のとおりに並んでいる必要があります。
`example.com/?a=1&b=2` というルールは `https://example.com/?b=2&a=1` には
効きません。特定の 1 つの値だけを見たいときは、その値がいちばん前に来る
URL でだけ使ってください。

### サブドメイン

既定では `example.com` のルールが `www.example.com` や `news.example.com` にも
効きます。設定で切れます。`example.com` が
`example.community` や `example.com.example.net` に効くことはありません。

## 知っておくとよいこと

### Firefox 自身のズーム記憶を書き換えます

Firefox はズームを**サイト (オリジン) 単位**で覚えます。パスごとに違う倍率を
当てるには、ページを開くたびに su-zoom が上書きするしかありません。
そのため、Firefox が覚えていたそのサイトの倍率は su-zoom の値に置き換わります。

「ルールに一致しないページ」を **「Firefox の設定にまかせる」** にすると、
ルールの無いページには手を出しません。ただしその場合、ルールを消した後も
そのサイトに以前の倍率が残ることがあります。100% に戻したいときは、
ポップアップの `100%` ボタンを押してください。

### 効かないページ

`http` と `https` のページだけが対象です。`about:` や `moz-extension:`、
PDF ビューアの内部ページなどにはズームを設定できません。

### Ctrl + ホイールはそのまま使えます

その場で変えた倍率は、ページを移動するまで残ります。移動するとルールの値に
戻ります。恒久的に変えたいときはポップアップから保存してください。

### プライバシー

- 設定はすべて **あなたの Firefox の中だけ** に保存されます。
- 外部のサービスへは何も送りません。閲覧しているページの中身も読みません。
- 権限は「保存領域」と「サイトへのアクセス」の 2 つです。後者は
  **開いているタブの URL を知るため** に使います。

## うまく動かないとき

**ルールを作ったのに効かない**
ポップアップを開くと「適用中のルール」が出ます。何も出ていなければ、
そのページにルールが当たっていません。ルール欄の下に
「このルールは今開いているページには当たりません」と出ていないか確認してください。

**思ったより広い範囲に効いてしまう**
前方一致なので、`example.com/cat` は `example.com/category` にも当たります。
末尾に `/` を付けてください。

**ルールを消したのに元の大きさに戻らない**
Firefox がそのサイトの倍率を覚えています。ポップアップの `100%` を押すか、
「ルールに一致しないページ」を「既定のズームにする (100%)」にしてください。
